# Supermart Sales Analysis – Data Analytics + AI

## Project objective
Analyze supermarket sales data to identify sales/profit trends, category and regional performance, customer/order patterns, and create a simple AI/ML-based sales forecast.

## Technology
- Python
- Pandas, NumPy
- Matplotlib
- Scikit-learn
- Excel
- Jupyter Notebook / VS Code

## Files
- `supermart_sales_data.csv` – project dataset
- `supermart_analysis.py` – complete Python analysis
- `Supermart_Sales_Analysis.xlsx` – dashboard and analysis tables
- `Supermart_Sales_Analysis_Report.docx` – report
- `Supermart_Sales_Analysis_Presentation.pptx` – presentation
- PNG files – charts used in the report

## How to run
```bash
pip install pandas numpy matplotlib scikit-learn openpyxl
python supermart_analysis.py
```

## AI component
A Linear Regression model is used on monthly historical sales to demonstrate short-term sales forecasting. The forecast is an educational project component and should not be presented as a production forecasting system.
